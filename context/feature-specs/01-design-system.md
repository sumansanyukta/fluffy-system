Read `AGENTS.md` before starting.

We're adding the design system and UI primitive componnets.

Install and configure `shadcn/ui`.

Add these shadcn componnets:
-Button
-Card
-Dialog
-Input
-Tabs
-Textarea
-ScrollArea

Do not modify the generated `components/ui/*` files after installation.

Also Install `lucide-react`.

Create `lib/utils.ts` with reusable `cn()` helper for merging Tailwind classes.

Ensure all componnets match the existing dark theme in `glabal.css`.

### Check when done
-All components import without errors
-`cn()` works properly
- No default light styling appears
